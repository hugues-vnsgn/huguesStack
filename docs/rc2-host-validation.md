affected target. Android/Gradle or iOS/Xcode context alone establishes no
implementation language. An explicit language request supports a provisional
preview; source evidence must be checked before execution. A Kotlin build-script
DSL does not establish an app's language.

prompt. Expected fixture answers were withheld. Actual successful tool reads
and returned source content were checked against the scoped Java, Kotlin and
Swift fixture bytes. Each host/variant selected `build-doctor` for all six cases
