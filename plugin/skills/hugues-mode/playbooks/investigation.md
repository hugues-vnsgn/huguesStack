# Investigation

source: Adapted from pstack 0.15.9 at `e43c7ee26e0038c6c1fa8380dd34ce86ff94cb2a`, `pstack/skills/poteto-mode/playbooks/investigation.md`; MIT notice in PSTACK-LICENSE.

Own the answer. This route is read-only and ends with an explanation or recommendation.

## Steps

1. Read the affected subsystem and its repository instructions. Use the owner's available `how` skill; use `why` for motivation or regression history. If either is unavailable, state the gap and cite the files or history inspected directly.
2. Keep one throughput item: `throughput checkpoint: n/a, read-only investigation`.
3. Produce an explanation with Overview, Key Concepts, How It Works, Where Things Live and Gotchas, or a recommendation with a tradeoffs table. Cite each material claim to source evidence and separate observed facts from hypotheses.
4. Apply the owner's available `unslop` skill to the reply. Finish when the answer addresses the original question and lists unresolved facts; route any requested implementation as a new task with its own authority.

**Reply:** the cited answer, judgment and remaining uncertainty. Investigation authorizes no consumer edits, execution, PR or architecture implementation.
