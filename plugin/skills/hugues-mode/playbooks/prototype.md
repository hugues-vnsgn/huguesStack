# Prototype

source: Adapted from pstack 0.15.9 at `e43c7ee26e0038c6c1fa8380dd34ce86ff94cb2a`, `pstack/skills/poteto-mode/playbooks/prototype.md`; MIT notice in PSTACK-LICENSE.

Own the decision. The artifact is throwaway; the production implementation follows the matching domain route.

## Steps

1. State the decision: layout, interaction, density, behavior, timing or approach. Without a decision to compare, use [hugues-mode precedence](../SKILL.md) to select the matching production route: [feature](feature.md), [kmp-bridge-change](kmp-bridge-change.md) or [cmp-two-target-change](cmp-two-target-change.md). Pin the scratch destination and permitted writes; a generic mode request does not authorize consumer copies, edits or app execution.
2. Gather references when the design space is open and name the directions to compare. For a structural design decision, read [architect](../../architect/SKILL.md) in full and use its design-only workflow; for competing executable experiments, read [arena](../../arena/SKILL.md) in full and use its isolated candidates and verified synthesis. Keep all artifacts throwaway and within scratch authority. If the direction is already fixed, retain this step with its skip reason.
3. Brief a fresh implementation subagent to build the smallest throwaway instrument in the authorized scratch directory. Use a lightweight rendering stack for visual alternatives or a minimal script for an empirical question. Keep production source intact; the worker owns the artifact directly and does not recursively delegate.
4. Put alternatives behind a labeled switcher when comparison requires them. Retain this step with its skip reason for a single experiment; each new build round uses a fresh worker.
5. Inspect and observe the artifact yourself on the decision's matching surface. Capture each visual variant and drive its interaction, or record the behavior/output/timing under the stated conditions. For a native mobile decision, use [mobile lanes](../references/mobile-lanes.md) and disclose missing runtime authority or tools.
6. Get an independent fresh review of whether the evidence answers the decision. Present alternatives, tradeoffs, recommendation, scratch path and limits; hand the selected direction back to [hugues-mode precedence](../SKILL.md) for production work through [feature](feature.md), [kmp-bridge-change](kmp-bridge-change.md) or [cmp-two-target-change](cmp-two-target-change.md), matching the recorded domain.

**Reply:** variants, observations, recommendation and artifact path. Label the result throwaway and identify observations that remain unrun.
